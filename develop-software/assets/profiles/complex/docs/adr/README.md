# Architecture Decision Records

ADRs preserve architecture-significant decisions and rationale. They do not represent Feature progress.

Naming:

```text
docs/adr/ADR-NNNN-<lowercase-kebab-slug>.md
```

Lifecycle:

```text
proposed -> accepted -> superseded
        \-> rejected
```

Accepted ADR semantics are frozen. Supersede the decision rather than rewriting it. Create records from [`../templates/adr.md`](../templates/adr.md).
