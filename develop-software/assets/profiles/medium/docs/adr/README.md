# Architecture Decision Records

Use ADRs only for architecture-significant decisions that affect multiple Features, cost substantial effort to reverse, or need durable rationale.

Naming:

```text
docs/adr/ADR-NNNN-<lowercase-kebab-slug>.md
```

Lifecycle:

```text
proposed -> accepted -> superseded
        \-> rejected
```

Accepted ADR semantics are frozen. Create a successor instead of rewriting the original decision. Create ADRs from [`../templates/adr.md`](../templates/adr.md).
