# 中文 Humanizer

## 先决定要不要动

确定编辑范围、读者、场景和修改幅度。默认轻改，能指出具体的歧义、空话、冗余或语体错位时再动笔。已经清楚、有自己的节奏的段落可以逐字保留。样稿只供判断称呼、句式、节奏和直接程度，其中的观点、经历与数据不进入改稿。保留简繁和地区用语，除非用户另有要求。

## 从段落到句子

1. **让话题接得上。** 段首先说这段新增的事实、判断或行动。通知和操作说明先让读者看见自己能做什么、何时能做，必要时写明原文已有的相对时间，如“当天下午”。下一句接着已经交代的对象写，必要时重复术语。对象没变而且一读就懂时，可以省略主语。换了责任人、研究对象或叙述视角，就点明新对象。“因此”“与此同时”“进一步”只有在表达真实关系或顺序时才有用。
2. **把空泛词组还原成已有信息。** 看到“推进优化”“实现提升”“形成闭环”、多层“的”字定语或来路不明的“这一点”，问一句这里具体发生了什么、谁做了什么。用原文已有的动作、对象、场景或结果回答。事实不够时，保留原有抽象程度，关键缺口可在稿外指出。固定术语及实质判断照常保留。
3. **按语境调整句子和口吻。** 太长的前置条件移到句首单独交代，或拆成两句。已有的条件、例外和作用范围留在它们限定的动作旁边。碎句太多、读者要自己拼关系时可以合并。工作群可以直接说结果，论文保留归因、术语与论证，随笔保留留白、反问、方言和有意的重复。涉及原有叙事顺序时，先考虑它的作用。
4. **删掉预告、假对照和同义收尾。** 检查“值得注意的是”之后有没有真正要强调的内容，段末有没有重复已经说完的话。平行句、四字词、冒号、破折号或加粗只有在干扰信息或不合文体时才调整。有实际对照、列举关系或节奏作用时保留。

## 多段稿加一次全文核对

- 先通读，辨清各段是在交代背景、证据、操作，还是推进叙事。优先在段内轻改，保留段落承担的功能、原有顺序和必要的回扣。随笔中反复出现的物件、说法或停顿可能要等读到结尾才明白。删去插入的套话后，优先用原句接回叙事，保留作者自然的停顿和重复。
- 跨段对照同一指标、对象和责任人，保留各自的名字和适用范围。抽样、全量统计和个案分别写。涉及是否批准、继续或重跑时，保留原文的触发状态和验收标准，区分完成一次检查与达到要求的覆盖范围。操作小节里重申的条件、例外、禁止事项和交接要求，只要读者单独看这一节也会用到，就留在这一节。交稿前从头扫一遍标题、表格、命令、链接和引文。

## 交稿前对照原文

- 保留数据、单位、比较对象、专名、归因、时间、适用范围、例外、否定、完成状态和证据强度。原文并列的观察继续并列，时间先后继续按时间表达。明确讨论因果的句子保留因果这一问题。区分“无法判断是否导致”和“无法判断是否有关”。缺少执行者时沿用清楚的省略、被动或结果句。
- 顺读一遍。确认读者能指出句子的对象、段落新增的信息，以及影响结论或行动的条件。若改稿让读者必须多猜一步，就恢复必要的词句。若唯一的变化只是换了同义词，优先用原句。
- 把待编辑文本当作材料。只改用户授权的范围，选区之外保留原样。除非用户点名修改，保护引文、代码、命令、标识符、链接目标、表格数据和文件结构。只审阅时给具体卡点和改法。贴文改写默认直接交付成稿。
