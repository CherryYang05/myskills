# Humanizer 调研与试改档案

- [研究笔记](humanizer-research.md) 汇总中英文研究、发现和编辑规则，附原始来源链接。用户提供的论文标题截图及中文图解所涉及的主要论点，已在[首版调研](baselines/first-draft-research.md)中对照论文核验。原始论文和第三方配图通过出处查阅。
- [短稿对照报告](humanizer-comparison.md) 与 [短稿试改记录](short-trial/) 保存样稿、逐版改稿、盲评、通知复测和汇总脚本。
- [长稿对照报告](humanizer-long-comparison.md) 与 [长稿试改记录](long-trial/) 保存原稿、直接改写对照、上游与自研版本的输出、双语盲评、结构检查和最终定点复核。
- [基线快照](baselines/) 保存测试所用的早期自研说明和两份上游说明。英文基线来自 [blader/humanizer v3.1.0](https://github.com/blader/humanizer/blob/main/SKILL.md)，文件 Git blob 为 `19fc634208e8cc6ae55d4ff287152583216fd244`。中文基线来自 [op7418/Humanizer-zh 的 2026-09-23 修订](https://github.com/op7418/Humanizer-zh/blob/main/SKILL.md)，文件 Git blob 为 `ef07b54da21a41d4a7e4fe0b0afb928f597eb684`。两份上游说明沿用各自随附的 MIT 许可。

试改材料均为自拟样稿。归档脚本保留试验时的目录约定和汇总口径。日常运行 Skill 时只需按主说明读取必要的编辑示例。
