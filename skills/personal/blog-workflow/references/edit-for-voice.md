# 第二遍按作者的文风编辑

用这遍把文章从写完变成能读。样文优先取用户指定的文章或已认可的稿件。技术文章可以保留准确的术语和长句，但每个段落要有一个正在解释的对象。参考样文怎样引入对象、接续算例和结束一节，保留作者在素材里表达过的判断。

- 先找删掉也不影响推理的句子。引入结论、宣布接下来要解释什么、在段末再说一遍，常常可以直接删。
- 读上下两段，找重复推理和整齐到机械的句式。重组段落，不只换同义词。标题写读者在这一段需要找的内容，正文无需再复述标题。
- 算例已经在正文时，把抽象总结换成一个会改变结果的具体输入。比如，直接写「A 的两项需求都翻倍，读取带宽刚好用完，显存只用到 60 GB」。让算例在需要时继续推导。
- 末段检查是不是在重列文章讲过的点。删去复述后可以直接停在最后一个有信息量的细节。作者没讲过的实测、感受、经历和口头禅不用补。
- 修完单独读一遍修改处和前后文。核对公式、单位、链接、命令、输出及示意和实测的区别。第一次审稿发现的理解障碍也要在成稿中修掉。
