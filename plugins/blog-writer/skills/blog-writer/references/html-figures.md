# 不依赖样式的 HTML 配图

这些片段面向会清理内联样式的 Markdown 编辑器。把行列关系直接写进 HTML，最终嵌入正文时去掉代码围栏；片段内部不插入 Markdown 或空行。按文章的数据改写标签与数字，字符 `<`、`>`、`&` 在文字中分别转义为 `&lt;`、`&gt;`、`&amp;`。

## 分组关系：多个 Q 头共享 K/V

这是教学设定：32 个 Q 头、8 组 K/V，每组 4 个 Q 头。K 与 V 是两份向量，不要用横排卡片的位置暗示共享关系，直接在同一行写清对应项。

```html
<div>
<table>
<thead><tr><th>Q 头</th><th>共享的 K、V</th><th>每个向量</th></tr></thead>
<tbody>
<tr><td>Q 0–3</td><td>K₀、V₀</td><td>128 个元素</td></tr>
<tr><td>Q 4–7</td><td>K₁、V₁</td><td>128 个元素</td></tr>
<tr><td>Q 8–27</td><td>K₂–K₆、V₂–V₆（5 组）</td><td>128 个元素</td></tr>
<tr><td>Q 28–31</td><td>K₇、V₇</td><td>128 个元素</td></tr>
</tbody>
</table>
</div>
```

第三行合并展示了 5 组，不表示 20 个 Q 头共享同一对 K/V。每层每个 token 共保存 8 个 K 向量和 8 个 V 向量。FP16 下为 8 × 128 × 2 × 2 = 4,096 bytes；图旁需说明这是单层、单 token 的数据量。

## 阶段对照：压缩、传输、解压串行执行

教学条件：原始 100 MiB，压缩后 40 MiB，链路 10 MiB/s；压缩 7 s、解压 1 s。阶段依次执行，行顺序表示先后，不用方框宽度冒充时间刻度。

```html
<div>
<table>
<thead><tr><th>依次执行的阶段</th><th>直接传输</th><th>压缩后传输</th></tr></thead>
<tbody>
<tr><td>① 压缩</td><td>0 s</td><td>7 s</td></tr>
<tr><td>② 传输</td><td>10 s</td><td>4 s</td></tr>
<tr><td>③ 解压</td><td>0 s</td><td>1 s</td></tr>
<tr><td>总耗时</td><td>10 s</td><td>12 s</td></tr>
</tbody>
</table>
</div>
```

两条路径以“接收端拿到可用原始文件”为同一完成标准。链路改为 5 MiB/s 时，传输行应同步改为 20 s、8 s，总耗时改为 20 s、16 s。若存在流水线重叠，重新分析完成时间，不能沿用串行求和。

## 验收

按目标渲染器清理后的 HTML 检查表头、单元格对应关系、步骤顺序和正文衔接。再去除样式检查一次，并在窄屏查看实际换行。默认片段不需要站点放开 `style` 或脚本；可用主题自身的表格样式改善外观，但不可依赖它表达关系。上述预检不替代具体 Halo 编辑器和主题的线上验收。
