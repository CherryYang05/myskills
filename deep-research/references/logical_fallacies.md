# 逻辑谬误目录 — 30+ 种供研究审查的谬误

## 目的
研究中常见逻辑谬误的参考目录。供 devils_advocate_agent 使用。

## 形式谬误（无效的逻辑结构）

### 1. 肯定后件 (Affirming the Consequent)
**结构**：如果 P 则 Q；Q 为真；因此 P 为真。
**示例**："如果一所大学拥有高额科研经费，它的成果就好。这所大学的成果好。因此，它一定拥有高额科研经费。"
**问题**：Q 可能有多种原因。

### 2. 否定前件 (Denying the Antecedent)
**结构**：如果 P 则 Q；非 P；因此非 Q。
**示例**："如果入学人数增加，收入就会增加。入学人数没有增加。因此，收入没有增加。"
**问题**：收入可能来自其他来源增加。

### 3. 中项不周延 (Undistributed Middle)
**结构**：所有 A 都是 B；所有 C 都是 B；因此所有 A 都是 C。
**示例**："所有成功的项目都使用技术。我们的项目使用技术。因此，我们的项目是成功的。"
**问题**：B（使用技术）是共有的，但并未将 A 和 C 联系起来。

### 4. 虚假两难 / 虚假二分法 (False Dilemma / False Dichotomy)
**结构**：要么 A 要么 B；非 A；因此 B。
**示例**："我们要么完全采用在线学习，要么维持传统方法。"
**问题**：许多混合选项是存在的。

## 非形式谬误

### 相关性谬误

### 5. 人身攻击 (Ad Hominem)
**描述**：攻击提出论点的人而非论点本身。
**研究示例**："这项研究的结论不可靠，因为作者在营利性大学工作。"
**正确做法**：评估方法论和证据，而非作者的隶属关系（尽管利益冲突应予以注明）。

### 6. 诉诸权威 (Appeal to Authority)
**描述**：仅仅因为权威人物认可就接受某个主张。
**研究示例**："发表在《自然》上，所以这些发现一定是有效的。"
**正确做法**：即使是最有声望的期刊也会发表有缺陷的研究。应根据其学术价值进行评估。

### 7. 诉诸传统 (Appeal to Tradition)
**描述**：论证某事是正确的，因为它一直是这样做的。
**研究示例**："这个指标已经使用了30年，所以一定是最好的衡量标准。"
**正确做法**：评估该指标在当前情境下是否仍然有效。

### 8. 诉诸新潮 (Appeal to Novelty)
**描述**：论证某事更好，因为它是新的。
**研究示例**："这个新框架一定优于既有的框架。"
**正确做法**：新颖性不等于改进。应基于证据进行比较。

### 9. 诉诸大众 / 从众谬误 (Appeal to Popularity / Bandwagon)
**描述**：论证某事是真的，因为许多人相信它。
**研究示例**："该领域的大多数研究者都使用这种方法，所以它一定是最好的。"
**正确做法**：流行程度不能验证方法论。应独立评估。

### 10. 红鲱鱼 (Red Herring)
**描述**：引入一个不相关的话题来转移对论证的注意力。
**研究示例**：通过讨论话题的重要性来回应对其方法论的批评。

### 证据谬误

### 11. 采摘樱桃 (Cherry-Picking) / 选择偏差
**描述**：选择支持结论的证据，同时忽略矛盾的证据。
**研究示例**：引用5项支持假设的研究，同时省略12项不支持的研究。
**检测方法**：将引用的来源与全面的检索结果进行比较。

### 12. 证实偏差 (Confirmation Bias)
**描述**：寻求、解释和记忆确认既有信念的信息。
**研究示例**：设计更可能返回支持性结果的检索词。
**检测方法**：检查检索策略是否中立；寻找是否主动寻求了反驳证据。

### 13. 幸存者偏差 (Survivorship Bias)
**描述**：仅从"幸存者"（成功者）中得出结论，忽略未幸存者。
**研究示例**："所有排名靠前的大学都实施了X"——忽略了实施了X但未改善的大学。
**检测方法**：问"那些失败的呢？"

### 14. 轶事证据 (Anecdotal Evidence)
**描述**：以个别故事作为一般性主张的证明。
**研究示例**："有一所大学在品牌重塑后入学人数增加了两倍，所以品牌重塑驱动了入学增长。"
**检测方法**：这是系统性发现还是孤立案例？

### 15. 草率概括 (Hasty Generalization)
**描述**：从不足的证据中得出广泛的结论。
**研究示例**："来自台湾的三个案例研究显示了X，因此这适用于所有亚洲大学。"
**检测方法**：样本是否具有代表性？概括是否与证据相称？

### 因果谬误

### 16. 后此谬误 (Post Hoc Ergo Propter Hoc)
**描述**：假设因为 B 继 A 之后发生，所以 A 导致了 B。
**研究示例**："在实施新课程后，毕业率提高了。因此，新课程导致了改善。"
**检测方法**：是否存在混杂因素？是否有对照组？

### 17. 共此谬误 (Cum Hoc Ergo Propter Hoc) / 相关不等于因果
**描述**：假设相关性意味着因果关系。
**研究示例**："国际学生更多的大学排名更高，所以国际学生导致了更高的排名。"
**检测方法**：是否存在合理的机制？两者是否可能由第三个因素引起？

### 18. 因果倒置 (Reverse Causation)
**描述**：将原因和结果弄反。
**研究示例**："优良的设施吸引学生"，而实际上是"学生的学费资助了更好的设施"。
**检测方法**：考虑时间顺序和替代的因果方向。

### 19. 生态谬误 (Ecological Fallacy)
**描述**：从群体层面数据推断个人层面的结论。
**研究示例**："教育支出更多的国家GDP更高，所以教育支出使个人更富有。"
**检测方法**：个人层面和群体层面的关系是否相同？

### 20. 辛普森悖论 (Simpson's Paradox)
**描述**：子群体中存在的趋势在合并群体后发生逆转。
**研究示例**：A系和B系都显示出留存率在改善，但大学整体显示出留存率在下降（由于入学比例的变化）。
**检测方法**：始终将分类数据与汇总数据一起检查。

### 推理谬误

### 21. 稻草人 (Straw Man)
**描述**：歪曲对手的论点以便更容易攻击。
**研究示例**：批评者说"这种方法有局限性" -> 作者回应"我的批评者说整项研究毫无价值"。
**检测方法**：反驳是否针对了实际的批评？

### 22. 移动球门 (Moving the Goalposts)
**描述**：在看到结果后更改成功的标准。
**研究示例**：将"项目成功"定义为入学增长，然后在入学下降时转变为"学生满意度"。
**检测方法**：成功标准是否预先定义？

### 23. 滑坡谬误 (Slippery Slope)
**描述**：论证一个行动将不可避免地导致极端的结果。
**研究示例**："如果我们允许灵活的录取标准，学术标准将彻底崩溃。"
**检测方法**：链条中的每一步是否真的可能？

### 24. 循环论证 (Circular Reasoning) / 乞求问题
**描述**：结论在前提中被假设。
**研究示例**："这所大学很优秀，因为它排名很高，而它排名很高是因为它很优秀。"
**检测方法**：论证是否依赖于它试图证明的事物的真实性？

### 25. 没有真正的苏格兰人 (No True Scotsman)
**描述**：重新定义一个类别以排除反例。
**研究示例**："所有质量保证系统都能改善成果。" "但系统X没有。" "嗯，X不是一个真正的质量保证系统。"
**检测方法**：定义是否被修改以适应主张？

### 26. 模棱两可 (Equivocation)
**描述**：在同一论证中以两种不同含义使用一个术语。
**研究示例**："质量"有时用来表示"标准合规"，有时用来表示"学生满意度"。
**检测方法**：关键术语在整个过程中是否定义一致？

### 统计谬误

### 27. 基率忽视 (Base Rate Neglect)
**描述**：忽视基率（总体概率），偏向具体信息。
**研究示例**："这个项目有90%的满意度"——但所有项目的基率是88%。
**检测方法**：始终与相关基率进行比较。

### 28. 均值回归 (Regression to the Mean)
**描述**：极端表现自然倾向于在后续测量中回归平均水平。
**研究示例**："我们的干预改善了表现最差的学生的分数"——他们可能本来就会改善。
**检测方法**：是否有对照组？初始测量是否极端？

### 29. 德克萨斯神枪手 (Texas Sharpshooter)
**描述**：通过聚焦聚类并忽略未命中，在随机数据中发现模式。
**研究示例**：运行20项统计检验，仅报告1项显著的。
**检测方法**：假设是否预先注册？是否对多重检验进行了校正？

### 30. 赌徒谬误 (Gambler's Fallacy)
**描述**：相信过去的随机事件会影响未来的随机事件。
**研究示例**："这个机构已经衰退了5年，所以该好转了。"
**检测方法**：是否存在逆转的因果机制，还是仅仅是在寻找模式？

### 31. 麦克纳马拉谬误 (McNamara Fallacy) / 量化偏差
**描述**：仅基于量化指标做决策，忽略质性因素。
**研究示例**：仅按发表论文数量对大学排名，忽略教学质量和社区影响。
**检测方法**：重要但难以衡量的因素是否被排除了？

### 32. 古德哈特定律 (Goodhart's Law)
**描述**："当一个衡量指标成为目标时，它就不再是好的衡量指标。"
**研究示例**：大学针对排名指标作弊，而非真正改善质量。
**检测方法**：该指标是否已成为目标？是否有指标操纵的迹象？

## 快速参考：检测问题

| 问这个问题 | 可检测 |
|----------|---------|
| "B是否有其他可能的原因？" | 后此谬误、虚假原因 |
| "那些失败的呢？" | 幸存者偏差 |
| "这个样本有代表性吗？" | 草率概括 |
| "标准是否在结果之前定义？" | 移动球门、德克萨斯神枪手 |
| "关键术语使用是否一致？" | 模棱两可 |
| "基率是多少？" | 基率忽视 |
| "遗漏了什么证据？" | 采摘樱桃、证实偏差 |
| "这是实际提出的论点吗？" | 稻草人 |
| "我们能区分相关和因果吗？" | 共此谬误、生态谬误 |
| "个人层面和群体层面是否被混用？" | 生态谬误、辛普森悖论 |
