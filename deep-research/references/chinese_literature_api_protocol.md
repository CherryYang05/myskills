# 中文文献 DOI 核验协议（本地中文适配，上游 #595）

**状态**：仅供 Agent 手动核验与可信编排层参考，**未接入自动引用验证门控**。上游实现位于 `scripts/chinese_literature_client.py`，本仓库没有该脚本，也没有 `shared/` 编排依赖。以下为上游 2026-07-27 至 2026-08-01 的历史验证观察，当前可用性需在实际使用时重新确认。

## 为什么需要

Crossref 是 DOI 注册机构之一，中文 DOI 还可能由 ISTIC、CNKI 等机构注册。Crossref 404 或 OpenAlex 无匹配不能直接推出「论文不存在」。反过来，`doi.org` 可解析只能说明标识符可能存在，**不能证明所引标题、作者、年份、页码正确**。

## 可参考的四类核验路径

1. **注册机构查询**：`https://doi.org/doiRA/<prefix>` 可识别部分 DOI 前缀对应的 RA。上游示例：`10.3760` / `10.3969` 为 ISTIC，`10.13209` 为 CNKI，`10.1360` 为 Crossref。必须校验响应中的 DOI 回显与 RA 字段，未知或异常响应不产生匹配结论。
2. **DOI 内容协商**：向 `https://doi.org/<doi>` 请求 `Accept: application/vnd.citationstyles.csl+json`，只有在受信任的 HTTPS 路径内得到结构完整、DOI 回显一致、包含原始中文题名与刊名的元数据时，才可能进行标题核验。**拒绝跳转至明文 HTTP、裸 IP 或未获批准的域名**；不得将跳转后的不可信内容当成核验结果。
3. **Handle 存在性检查**：`https://hdl.handle.net/api/handles/<doi>` 的结构化响应可提供标识符存在性证据，但存在性与书目信息匹配是不同维度；未知状态、解析异常、超时都只能记为不可用。
4. **PubMed E-utilities**：仅针对实际被 PubMed 覆盖的中文医学期刊，可在已核实 ISSN / NLM 缩写后按卷、首页等坐标检索。期刊出现在 NLM Catalog 不等于该期刊有 PubMed 论文记录；无记录或检索失败不应直接判为造假。使用时遵守 NCBI 邮箱标识和请求速率限制。

## 结论语义与人工确认

- **标识符存在**：仅能证明该 DOI/Handle 的存在性；标题、刊名、作者、页码等仍需独立核对。
- **元数据匹配**：必须有可信元数据及可复核的中文题名/刊名对照证据，必要时人工核对原文。
- **不匹配或不可用**：区分可信的标识符反证与覆盖不足、网络错误、跳转被拒等未知状态。缺少证据时输出 `UNVERIFIED`，保留检索路径、日期与失败原因，不将未命中自动升级为伪造判定。

不得绕过登录、付费墙、访问控制或站点条款获取元数据；不得在日志中暴露访问密钥。此文件为对上游协议的**精简适配**，未覆盖原实现的完整输入校验、模糊匹配阈值与错误状态机。
