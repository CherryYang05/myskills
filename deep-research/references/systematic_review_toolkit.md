# 系统综述工具包 — 参考指南

## 目的

开展系统综述（Systematic Review）和 Meta分析（Meta-analysis）的综合参考。涵盖 Cochrane 手册（Cochrane Handbook）方法论、PRISMA 2020 报告规范、偏倚风险（Risk of Bias）评估工具、异质性（Heterogeneity）解读、GRADE 证据确定性框架以及方案注册。供 `risk_of_bias_agent`、`meta_analysis_agent`、`bibliography_agent` 和 `report_compiler_agent` 使用。

---

## 1. Cochrane 手册 v6.4 — 核心原则

Cochrane 手册（Cochrane Handbook for Systematic Reviews of Interventions，v6.4, 2023）是系统综述方法学的金标准参考。

### 核心方法学阶段

| 阶段 | Cochrane 手册章节 | 关键要求 |
|------|-------------------|---------|
| 规划 | 第1-3章 | 方案注册，明确目标，PICOS |
| 检索 | 第4章 | 全面检索（≥ 2个数据库），记录检索策略 |
| 筛选 | 第4章 | 独立双筛，预设纳入标准 |
| 数据提取 | 第5章 | 标准化表格，预试验，双人提取 |
| 偏倚风险 | 第8章 (RoB 2)，第25章 (ROBINS-I) | 基于域的评估，信号问题 |
| 证据合成 | 第10-12章 | 恰当的统计方法，异质性评估 |
| GRADE | 第14章 | 每个结局的证据确定性 |
| 报告 | 第15章 | 符合 PRISMA 2020 |

### 基本原则

1. **先验方案（A priori protocol）**：在开展综述之前注册方案（PROSPERO, OSF）
2. **全面检索**：检索多个数据库；不要仅依赖单一来源
3. **双人独立流程**：两名综述者独立进行筛选、数据提取和偏倚风险评估（至少针对部分研究）
4. **预设方法**：在看到结果之前定义分析计划
5. **透明报告**：记录一切；另一个团队应能够复制该综述

## 2. PRISMA 2020 — 完整27项清单

**全称**：系统综述和 Meta分析优先报告条目（Preferred Reporting Items for Systematic Reviews and Meta-Analyses）
**参考文献**：Page et al. (2021). BMJ, 372, n71. https://doi.org/10.1136/bmj.n71

### 标题和摘要

| # | 条目 | 指南 |
|---|------|------|
| 1 | **标题** | 将报告标识为系统综述、Meta分析或两者兼有 |
| 2 | **摘要** | 结构化摘要：背景、目的、数据来源、研究纳入标准、参与者、干预措施、研究评估/合成方法、结果、局限性、结论、注册号 |

### 引言

| # | 条目 | 指南 |
|---|------|------|
| 3 | **理由** | 在现有知识背景下描述开展综述的理由 |
| 4 | **目的** | 提供明确的问题陈述，参考 PICOS |

### 方法

| # | 条目 | 指南 |
|---|------|------|
| 5 | **纳入排除标准** | 明确纳入和排除标准（PICOS 组成部分、日期范围、语言、发表状态） |
| 6 | **信息来源** | 描述检索的所有信息来源（数据库、注册库、网站、组织、参考文献列表）及检索日期 |
| 7 | **检索策略** | 呈现至少一个数据库的完整检索策略，包括任何筛选条件和限制 |
| 8 | **筛选过程** | 说明决定哪些研究符合纳入标准的方法（综述者人数、共识达成过程） |
| 9 | **数据收集过程** | 描述数据提取的方法（综述者人数、是否独立进行、从研究者获取/确认数据的任何过程） |
| 10 | **数据条目** | 列出并定义所有结局变量和其他提取的变量 |
| 11 | **研究偏倚风险评估** | 描述评估纳入研究偏倚风险的方法，包括所使用的工具及结果如何用于证据合成 |
| 12 | **效应量** | 明确每个结局所使用的效应量（Effect measure）（如 RR、MD、SMD） |
| 13a | **合成方法** | 描述决定哪些研究有资格纳入每次合成的过程 |
| 13b | | 描述为准备数据合成所需的任何方法（如处理多臂研究） |
| 13c | | 描述用于以表格或可视化方式展示单项研究和合成结果的任何方法 |
| 13d | | 描述合成结果所用的任何方法及理由（Meta分析：模型、软件；叙述性合成：SWiM） |
| 13e | | 描述探索异质性可能原因的任何方法（亚组分析、Meta回归） |
| 13f | | 描述所进行的任何敏感性分析（Sensitivity analysis） |
| 14 | **报告偏倚评估** | 描述评估因结果缺失导致的偏倚风险的任何方法（发表偏倚） |
| 15 | **确定性评估** | 描述评估证据体确定性的任何方法（如 GRADE） |

### 结果

| # | 条目 | 指南 |
|---|------|------|
| 16a | **研究筛选** | 描述检索和筛选过程的结果，最好使用 PRISMA 流程图 |
| 16b | | 引用看似符合纳入标准但被排除的研究，并说明排除原因 |
| 17 | **研究特征** | 对每项纳入研究进行引用并呈现其特征 |
| 18 | **研究中的偏倚风险** | 呈现每项纳入研究的偏倚风险评估结果 |
| 19 | **单项研究结果** | 对所有结局，呈现每项研究的：汇总数据、效应估计值和置信区间（Confidence interval, CI）、合成结果 |
| 20a | **合成结果** | 对每次合成，简要总结纳入研究的特征和偏倚风险 |
| 20b | | 呈现所进行的所有统计合成的结果，包括 CI 和异质性度量 |
| 20c | | 呈现所有异质性可能原因调查的结果 |
| 20d | | 呈现所有敏感性分析的结果 |
| 21 | **报告偏倚** | 呈现因结果缺失导致的偏倚风险评估 |
| 22 | **证据确定性** | 呈现每个评估结局的证据确定性评估 |

### 讨论

| # | 条目 | 指南 |
|---|------|------|
| 23 | **讨论** | 在其他证据背景下对结果提供总体解读，讨论证据及综述过程的局限性、启示 |
| 24 | **注册和方案** | 提供注册信息，包括注册库名称和注册号，以及方案链接 |
| 25 | **资助** | 描述资金或非资金资助来源及资助者的角色 |
| 26 | **利益冲突** | 声明综述作者的任何利益冲突 |
| 27 | **数据、代码及其他材料的可获得性** | 报告以下哪些内容可公开获取：数据提取表格模板、从纳入研究中提取的数据、分析代码、任何其他材料 |

## 3. RoB 2 工具摘要

**全称**：随机试验偏倚风险工具第2版（Risk of Bias tool for randomized trials, version 2）
**参考文献**：Sterne et al. (2019). BMJ, 366, l4898. https://doi.org/10.1136/bmj.l4898

### 域

| 域 | 缩写 | 关注要点 |
|----|------|---------|
| 随机化过程产生的偏倚 | D1 | 序列生成、分配隐藏、基线平衡 |
| 偏离预期干预措施导致的偏倚 | D2 | 盲法、方案依从性、ITT 分析 |
| 结局数据缺失导致的偏倚 | D3 | 完整性、差异性脱落、缺失数据处理 |
| 结局测量中的偏倚 | D4 | 结局评估方法、评估者盲法 |
| 报告结果选择中的偏倚 | D5 | 预注册、选择性报告 |

### 判断尺度

- **低偏倚风险（Low risk of bias）**：判定该研究在此域的偏倚风险为低
- **存在一些担忧（Some concerns）**：该研究在此域的偏倚问题引起一些担忧
- **高偏倚风险（High risk of bias）**：判定该研究在此域的偏倚风险为高

### 总体判断算法

- 所有域均为 Low → 总体 **Low**
- ≥ 1个域为 Some Concerns，无 High → 总体 **Some Concerns**
- ≥ 1个域为 High → 总体 **High**

## 4. ROBINS-I 摘要

**全称**：非随机干预研究偏倚风险工具（Risk Of Bias In Non-randomized Studies of Interventions）
**参考文献**：Sterne et al. (2016). BMJ, 355, i4919. https://doi.org/10.1136/bmj.i4919

### 域（横跨3个时间点的7个域）

**干预前（Pre-intervention）**：
- D1：混杂导致的偏倚
- D2：研究参与者的选择偏倚

**干预时（At intervention）**：
- D3：干预分类偏倚

**干预后（Post-intervention）**：
- D4：偏离预期干预措施导致的偏倚
- D5：数据缺失导致的偏倚
- D6：结局测量偏倚
- D7：报告结果选择偏倚

### 判断尺度

- **低风险（Low risk）**：与设计良好的 RCT 相当
- **中等风险（Moderate risk）**：对于非随机研究而言是可靠的，但不能被视为与设计良好的 RCT 相当
- **严重风险（Serious risk）**：存在一些重要问题
- **极严重风险（Critical risk）**：研究问题过于严重，无法提供有用证据
- **无信息（No information）**：报告信息不足

## 5. I² 解读指南

| I² 范围 | 标签 | 含义 | 行动 |
|---------|------|------|------|
| 0-40% | 低 | 异质性可能不重要 | 继续合并；报告 I² |
| 30-60% | 中等 | 可能存在中等程度异质性 | 继续合并；调查异质性来源 |
| 50-90% | 实质性 | 存在实质性异质性 | 调查异质性来源；考虑亚组分析（Subgroup analysis）；报告预测区间 |
| 75-100% | 极大 | 存在极大异质性 | 质疑合并是否有意义；考虑叙述性合成 |

**重要注意事项**：
- 范围故意存在重叠（根据 Cochrane 手册 10.10.2）
- I² 的显著性取决于：效应量大小、Q 检验的 p 值以及森林图（Forest plot）的视觉检查
- 高 I² 但所有效应方向一致，比中等 I² 但效应跨零的情况更不令人担忧
- I² 受研究精度影响——许多精确研究即使绝对差异很小也可能产生高 I²
- 始终报告 I² 的 95% CI（当研究较少时此区间可能很宽）

## 6. GRADE 证据确定性框架

**全称**：建议分级、评估、制定与评价（Grading of Recommendations, Assessment, Development and Evaluations）
**参考文献**：Guyatt et al. (2008). BMJ, 336, 924-926.

### 起点水平

| 研究设计 | 起始确定性 |
|---------|-----------|
| 随机试验 | 高（HIGH, ⊕⊕⊕⊕） |
| 非随机研究 | 低（LOW, ⊕⊕◯◯） |

### 降低确定性的因素（降级）

| 因素 | 降级幅度 | 何时适用 |
|------|---------|---------|
| 偏倚风险 | -1 或 -2 | 研究设计/实施存在严重或非常严重的局限 |
| 不一致性 | -1 或 -2 | 无法解释的异质性（I² > 50%，效应方向不一致） |
| 间接性 | -1 或 -2 | 证据未能直接针对综述问题的 PICOS |
| 不精确性 | -1 或 -2 | 宽置信区间（CI）、小样本量、CI 跨越临床决策阈值 |
| 发表偏倚（Publication bias） | -1 | 漏斗图（Funnel plot）不对称、小研究效应、已知未发表试验 |

### 提高确定性的因素（升级 — 仅限观察性研究）

| 因素 | 升级幅度 | 何时适用 |
|------|---------|---------|
| 大效应 | +1 或 +2 | RR > 2 或 < 0.5（大），RR > 5 或 < 0.2（非常大），且不存在混杂因素 |
| 剂量-反应梯度 | +1 | 观察到明确的剂量-反应关系 |
| 合理的混杂 | +1 | 所有合理的混杂因素都会减小观察到的效应 |

### 确定性水平

| 水平 | 符号 | 含义 |
|------|------|------|
| 高（High） | ⊕⊕⊕⊕ | 非常确信真实效应接近估计值 |
| 中（Moderate） | ⊕⊕⊕◯ | 中等程度确信；真实效应可能接近估计值，但也可能存在实质性差异 |
| 低（Low） | ⊕⊕◯◯ | 信心有限；真实效应可能与估计值存在实质性差异 |
| 极低（Very Low） | ⊕◯◯◯ | 信心极低；真实效应很可能与估计值存在实质性差异 |

## 7. 方案注册指南

### 何时注册

- **始终**注册拟发表的系统综述
- **在**开始文献检索**之前**注册
- 注册可防止结局报告偏倚并证明先验规划

### 在哪里注册

| 平台 | 侧重点 | 费用 | 网址 |
|------|--------|------|------|
| **PROSPERO** | 卫生相关系统综述 | 免费 | crd.york.ac.uk/prospero |
| **OSF Registries** | 任何学科 | 免费 | osf.io/registries |
| **INPLASY** | 任何学科 | 约$40 | inplasy.com |
| **Research Registry** | 任何学科 | 系统综述免费 | researchregistry.com |

### 方案内容（PRISMA-P 2015）

完整方案模板参见 `templates/prisma_protocol_template.md`。

关键章节：
1. 标题、注册、作者、修订
2. 理由、目的、PICOS 纳入标准
3. 信息来源、检索策略、研究记录管理
4. 数据提取、偏倚风险评估、数据合成计划
5. Meta偏倚评估、累积证据的信心

## 快速决策指南

```
Starting a systematic review?
│
├── 1. Register your protocol
│   └── PROSPERO (health) or OSF (any field)
│
├── 2. Write your protocol
│   └── Use PRISMA-P template → templates/prisma_protocol_template.md
│
├── 3. Search systematically
│   └── ≥ 2 databases, document everything, PRISMA flow
│
├── 4. Screen and select
│   └── Dual screening, predefined criteria
│
├── 5. Assess risk of bias
│   └── RCTs → RoB 2 | Non-randomized → ROBINS-I
│
├── 6. Synthesize evidence
│   ├── Quantitative data + comparable studies → Meta-analysis
│   └── Otherwise → Narrative synthesis (SWiM)
│
├── 7. Assess certainty
│   └── GRADE for each outcome
│
└── 8. Report
    └── PRISMA 2020 checklist → templates/prisma_report_template.md
```
