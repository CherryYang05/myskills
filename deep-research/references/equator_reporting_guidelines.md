# EQUATOR 报告指南 — 研究设计与报告规范映射

## 目的
EQUATOR Network（Enhancing the QUAlity and Transparency Of health Research，促进健康研究的质量与透明度网络）报告指南快速参考。辅助 research_architect_agent 在方法论设计阶段选择合适的报告清单，以及 report_compiler_agent 在撰写阶段确保报告完整性。

---

## 1. 研究设计 → 报告规范映射表

| 研究设计 | 首选报告规范 | 适用场景 |
|----------|------------|---------|
| 系统综述 / Meta分析 | **PRISMA**（系统综述和Meta分析首选报告条目） | 整合多项研究的文献综述 |
| 随机对照试验 (RCT) | **CONSORT**（试验报告统一标准） | 随机分组的干预实验 |
| 观察性研究（队列、病例对照、横断面） | **STROBE**（流行病学观察性研究报告加强规范） | 非干预性定量观察研究 |
| 定性研究 | **COREQ**（定性研究报告统一标准） | 访谈、焦点小组、观察 |
| 质量改进研究 | **SQUIRE**（质量改进报告卓越标准） | 系统性质量改进项目报告 |
| 诊断准确性研究 | STARD | 诊断工具评估 |
| 预后研究 | TRIPOD | 预测模型开发与验证 |
| 病例报告 | CARE | 单个或少量深度病例报告 |
| 经济学评价 | CHEERS | 成本效益分析 |
| 混合方法研究 | GRAMMS | 定性-定量混合设计 |
| 动物研究 | ARRIVE | 动物实验 |
| 网状Meta分析 | PRISMA-NMA | 多重比较Meta分析 |
| 范围综述 | PRISMA-ScR | 范围综述（比系统综述要求略低） |

## 2. PRISMA — 系统综述精简清单

**全称**：Preferred Reporting Items for Systematic Reviews and Meta-Analyses（系统综述和Meta分析首选报告条目）
**版本**：PRISMA 2020（最新版）

### 核心报告条目

| # | 条目 | 描述 | 必要性 |
|---|------|------|--------|
| 1 | **标题** | 明确标识为系统综述（含或不含Meta分析） | 必需 |
| 2 | **摘要** | 结构化摘要（背景、目的、方法、结果、结论） | 必需 |
| 3 | **注册** | 注册号和注册平台（如PROSPERO） | 强烈推荐 |
| 4 | **纳入标准** | 以PICOS或PEO格式的纳入/排除标准 | 必需 |
| 5 | **信息来源** | 检索的数据库及日期 | 必需 |
| 6 | **检索策略** | 至少一个数据库的完整检索策略 | 必需 |
| 7 | **筛选过程** | 筛选流程（审稿人数量、分歧解决方式） | 必需 |
| 8 | **数据提取** | 数据提取方法 | 必需 |
| 9 | **偏倚风险** | 偏倚风险评估工具及结果 | 必需 |
| 10 | **合成方法** | 合成方法（叙述性 / Meta分析） | 必需 |
| 11 | **PRISMA流程图** | 文献筛选流程图 | 必需 |
| 12 | **结果** | 各研究特征、偏倚评估、合成结果 | 必需 |
| 13 | **讨论** | 证据确定性、局限性、与现有知识的关系 | 必需 |
| 14 | **资助** | 资金来源和利益冲突 | 必需 |

### PRISMA 流程图模板

```
Records identified (n = )
├── Database searching (n = )
└── Other sources (n = )
         ↓
Duplicates removed (n = )
         ↓
Records screened (n = )
├── Excluded (n = )
         ↓
Reports sought for retrieval (n = )
├── Not retrieved (n = )
         ↓
Reports assessed for eligibility (n = )
├── Excluded, with reasons (n = )
│   ├── Reason 1 (n = )
│   ├── Reason 2 (n = )
│   └── Reason 3 (n = )
         ↓
Studies included in review (n = )
├── In qualitative synthesis (n = )
└── In quantitative synthesis (meta-analysis) (n = )
```

## 3. CONSORT — 随机对照试验精简清单

**全称**：Consolidated Standards of Reporting Trials（试验报告统一标准）
**版本**：CONSORT 2010 + 扩展版

### 核心报告条目

| # | 条目 | 描述 |
|---|------|------|
| 1 | **标题与摘要** | 标识为RCT；结构化摘要 |
| 2 | **背景** | 科学背景和试验理由 |
| 3 | **目标** | 具体目标或假设 |
| 4 | **试验设计** | 设计类型（平行、交叉、析因等）及分配比例 |
| 5 | **参与者** | 纳入标准、研究场所、数据收集地点 |
| 6 | **干预措施** | 各组干预的具体描述（包括实施方式和时间） |
| 7 | **结局指标** | 主要和次要结局指标，包括定义和时间点 |
| 8 | **样本量** | 样本量计算方法（功效分析） |
| 9 | **随机化** | 随机序列生成方法、分配隐匿机制 |
| 10 | **盲法** | 盲法实施（谁被设盲、如何实施） |
| 11 | **统计方法** | 统计分析方法，ITT/PP分析 |
| 12 | **流程图** | 参与者流程图（招募 → 分配 → 随访 → 分析） |
| 13 | **结果** | 各组结果、效应量和精确度（CI） |
| 14 | **危害** | 不良事件或副作用 |
| 15 | **局限性** | 偏倚来源、不精确性、多重比较 |
| 16 | **注册** | 试验注册号 |

### 高等教育研究应用注意事项

教育领域的RCT（如比较教学方法）常面临：
- 无法完全随机化（整群随机化更常见）
- 难以实施盲法（教师/学生知道自己的分组）
- 建议使用 **CONSORT-SPI**（社会与心理干预扩展版）

## 4. STROBE — 观察性研究精简清单

**全称**：Strengthening the Reporting of Observational Studies in Epidemiology（流行病学观察性研究报告加强规范）
**适用于**：队列研究、病例对照研究、横断面研究

### 核心报告条目

| # | 条目 | 描述 |
|---|------|------|
| 1 | **标题与摘要** | 标明研究设计类型 |
| 2 | **背景** | 科学背景、研究理由 |
| 3 | **目标** | 具体目标、预先设定的假设 |
| 4 | **研究设计** | 明确说明研究设计（队列 / 病例对照 / 横断面） |
| 5 | **研究场所** | 场所、地点、相关日期（招募、暴露、随访） |
| 6 | **参与者** | 纳入标准、数据来源、抽样方法 |
| 7 | **变量** | 结局变量、暴露变量、潜在混杂因素、效应修饰变量 |
| 8 | **数据来源** | 各变量的数据来源和测量方法 |
| 9 | **偏倚** | 处理潜在偏倚来源的方法 |
| 10 | **研究规模** | 如何确定样本量 |
| 11 | **统计方法** | 统计方法（包括混杂因素处理、缺失数据处理） |
| 12 | **结果** | 描述性统计、主要结果（包括效应量、CI、p值） |
| 13 | **讨论** | 主要发现、局限性、可推广性、与其他研究的一致性 |
| 14 | **资助** | 资金来源 |

### 高等教育研究应用注意事项

高等教育中常见的观察性研究：
- 学生学习成果横断面调查 → 横断面STROBE
- 毕业生就业追踪 → 队列STROBE
- 辍学风险因素分析 → 病例对照STROBE

## 5. COREQ — 定性研究精简清单

**全称**：Consolidated Criteria for Reporting Qualitative Research（定性研究报告统一标准）
**适用于**：访谈、焦点小组

### 核心报告条目（32个条目，3个领域）

#### 领域1：研究团队与反思性

| # | 条目 | 描述 |
|---|------|------|
| 1 | **访谈者/主持人** | 谁进行了访谈或主持了焦点小组 |
| 2 | **资质** | 研究者资格 |
| 3 | **职业** | 研究者的专业身份 |
| 4 | **性别** | 研究者性别 |
| 5 | **经验与培训** | 定性研究经验和培训 |
| 6 | **与参与者的关系** | 研究者与参与者的关系 |
| 7 | **参与者知情** | 参与者对研究的了解程度 |

#### 领域2：研究设计

| # | 条目 | 描述 |
|---|------|------|
| 8 | **方法论取向** | 理论框架（如扎根理论、现象学） |
| 9 | **抽样** | 抽样策略和方法 |
| 10 | **接触方式** | 如何联系参与者 |
| 11 | **样本量** | 参与者人数 |
| 12 | **未参与** | 拒绝参与的人数和原因 |
| 13 | **研究场所** | 访谈地点 |
| 14 | **非参与者在场** | 访谈时是否有非参与者在场 |
| 15 | **样本描述** | 参与者人口学特征 |
| 16 | **访谈提纲** | 是否使用了访谈提纲以及是否进行了预测试 |
| 17 | **重复访谈** | 是否进行了重复访谈 |
| 18 | **录音/录像** | 是否进行了音频/视频录制 |
| 19 | **田野笔记** | 是否做了田野笔记 |
| 20 | **时长** | 访谈持续时间 |
| 21 | **数据饱和** | 是否讨论了数据饱和 |
| 22 | **转录稿返回** | 是否将转录稿返回给参与者审阅反馈 |

#### 领域3：分析与发现

| # | 条目 | 描述 |
|---|------|------|
| 23 | **数据分析** | 分析方法（如主题分析、IPA） |
| 24 | **软件** | 所用分析软件 |
| 25 | **参与者验证** | 参与者是否确认了研究发现 |
| 26 | **引文** | 是否呈现引文以支持主题 |
| 27 | **数据与发现的一致性** | 数据与发现之间的一致性 |
| 28 | **主要主题的清晰性** | 主要主题是否清晰呈现 |
| 29 | **次要主题的清晰性** | 次要主题是否清晰呈现 |

## 6. SQUIRE — 质量改进研究精简清单

**全称**：Standards for QUality Improvement Reporting Excellence（质量改进报告卓越标准）
**版本**：SQUIRE 2.0
**适用于**：质量改进项目、系统性质量改进、高等教育质量保障（QA）研究

### 核心报告条目

| # | 条目 | 描述 |
|---|------|------|
| 1 | **标题** | 标识为质量改进研究 |
| 2 | **摘要** | 结构化摘要 |
| 3 | **问题描述** | 质量问题的性质和严重程度 |
| 4 | **已有知识** | 已知的相关证据 |
| 5 | **理论依据** | 改进倡议的理论基础 |
| 6 | **具体目标** | 具体的改进目标（可量化） |
| 7 | **情境** | 改进的环境背景 |
| 8 | **干预措施** | 改进措施的具体描述 |
| 9 | **干预措施的研究** | 如何评估改进效果 |
| 10 | **测量指标** | 结局指标、过程指标、平衡指标 |
| 11 | **分析** | 定量/定性分析方法 |
| 12 | **伦理考量** | 伦理审查（如适用） |
| 13 | **结果** | 改进结果（包括时间序列数据） |
| 14 | **讨论** | 主要发现、与情境的关系、可推广性 |
| 15 | **局限性** | 研究局限性 |

### 特别适用于高等教育QA研究

SQUIRE 对以下高等教育质量保障研究特别有参考价值：
- **教学质量改进**：新教学策略的引入与评估
- **课程改革**：课程重新设计的效果追踪
- **学生支持服务改进**：辅导、咨询和学习支持的系统改进
- **HEEACT认证自我改进**：针对认证发现的改进行动与追踪
- **院校研究（IR）驱动的改进**：基于数据的决策与改进循环

## 7. 高等教育研究场景推荐

### 常用规范排名

| 排名 | 规范 | 高等教育常见使用场景 |
|------|------|----------------|
| 1 | **PRISMA** | 教育政策系统综述、教学策略Meta分析 |
| 2 | **COREQ** | 教师/学生体验访谈、焦点小组 |
| 3 | **STROBE** | 学生调查、院校数据分析 |
| 4 | **SQUIRE** | 教学质量改进、QA认证 |
| 5 | **CONSORT** | 教学干预实验（较不常见但影响力高） |

### 研究设计快速选择

```
What is your research type?
│
├── Integrating existing research → PRISMA
│   ├── Systematic review → PRISMA 2020
│   ├── Scoping review → PRISMA-ScR
│   └── Meta-analysis → PRISMA + MOOSE
│
├── Intervention experiment → CONSORT
│   ├── Individual randomization → CONSORT 2010
│   ├── Class/school randomization → CONSORT-Cluster
│   └── Social/psychological intervention → CONSORT-SPI
│
├── Observational survey → STROBE
│   ├── Cross-sectional survey → STROBE-CS
│   ├── Follow-up study → STROBE-Cohort
│   └── Retrospective comparison → STROBE-CC
│
├── Qualitative research → COREQ
│   ├── Interviews → COREQ
│   ├── Focus groups → COREQ
│   └── Ethnography → SRQR (alternative)
│
└── Quality improvement → SQUIRE
    ├── PDSA cycle → SQUIRE 2.0
    └── QA/accreditation improvement → SQUIRE 2.0
```

## 快速参考：选择报告规范的3个步骤

1. **确定研究设计**：你的研究属于什么类型的研究设计？
2. **查看映射表**：找到对应的报告规范
3. **下载清单**：前往 [EQUATOR Network](https://www.equator-network.org/) 下载完整清单

> 提醒：报告规范代表的是最低标准，而非质量上限。满足清单不保证研究质量高，但不满足清单通常意味着报告质量存在缺陷。
