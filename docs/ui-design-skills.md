## 验证范围

核对官方来源、提交版本、许可证、SKILL.md 与上游字节一致性，以及仓库的 Frontmatter、来源映射、README、marketplace 和更新保护校验。验证这些内容不等于独立的视觉质量评测或效果保证；实际界面仍应结合产品需求、截图和可访问性检查验收。

## 使用

- “用 frontend-design 设计这个软件的界面，先确定信息层级、布局和视觉方向，再实现。”
- “用 web-design-guidelines 检查这些 UI 文件，给出具体问题及修改建议。”
